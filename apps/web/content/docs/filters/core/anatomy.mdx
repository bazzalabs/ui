Let's take a look at the anatomy of the `Filter` component structure and composition.

We'll start zoomed in, with the `Filter.Item`:

A `Filter.Item` has four individual components:

- `Filter.Subject` displays the icon and name of the column represented by the filter.
- `Filter.Operator` displays the filter operator and doubles as a dropdown menu to change the operator.
- `Filter.Value` displays the current values applied on the filter and doubles as dropdown menu to mutate the filter value.
- `Filter.Remove` removes the filter when pressed.

- `Filter.Root` is the main container for the `Filter` sub-components.
- `Filter.Menu` is a dropdown menu to create new filters.
- `Filter.List` is the container for the current filters (i.e. `Filter.Item`).
- `Filter.Actions` is a container for actions which apply on the entire filters state.
- `Filter.Clear` is a button which clears all filters when pressed.

---

In code, we have the following structure:

```tsx
<Filter.Provider> // Context provider
  <Filter.Root>
      <Filter.Menu />
      <Filter.List>
        <Filter.Item>
          <Filter.Subject />
          <Filter.Operator />
          <Filter.Value />
          <Filter.Remove />
        </Filter.Item>
      </Filter.List>
    <Filter.Actions>
      <Filter.Clear />
    </Filter.Actions>
  </Filter.Root>
</Filter.Provider>
```
