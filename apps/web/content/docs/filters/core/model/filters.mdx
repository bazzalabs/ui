The state of the applied filters on a table is represented as `FiltersState`, which is an array of `FilterModel` objects.

## FilterModel

Each `FilterModel` represents a single filter for a specific column:

```ts
type FilterModel<TType extends ColumnDataType = any> = {
  columnId: string
  type: TType // option, multiOption, text, date, boolean, number
  operator: FilterOperators[TType] // i.e. 'is', 'is not', 'is any of', etc.
  values: FilterValues<TType>
}
```

### Properties

| Property | Type | Description |
|----------|------|-------------|
| `columnId` | `string` | The ID of the column this filter applies to. |
| `type` | `ColumnDataType` | The data type of the column. |
| `operator` | `FilterOperators[TType]` | The filter operator (e.g., "is", "contains"). |
| `values` | `FilterValues[TType]` | The filter values. |

## FiltersState

The complete filter state is simply an array of `FilterModel` objects:

```ts
type FiltersState = Array<FilterModel>
```

### Example

```ts
const filters: FiltersState = [
  {
    columnId: 'status',
    type: 'option',
    operator: 'is',
    values: ['backlog'],
  },
  {
    columnId: 'title',
    type: 'text',
    operator: 'contains',
    values: ['bug'],
  },
]
```

## Filter Values

The shape of `values` depends on the column's data type:

| Type | Values Shape | Example |
|------|-------------|---------|
| `text` | `string[]` | `['search term']` |
| `number` | `number[]` | `[10]` or `[0, 100]` (for "between") |
| `date` | `Date[]` | `[new Date()]` or `[startDate, endDate]` |
| `boolean` | `boolean[]` | `[true]` |
| `option` | `string[]` | `['backlog', 'todo']` |
| `multiOption` | `string[]` | `['label-1', 'label-2']` |

See [Operators](/docs/filters/core/model/operators) for the available operators per type.
