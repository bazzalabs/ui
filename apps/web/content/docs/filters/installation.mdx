## Registry

We recommend installing **both** the `<Filter />` component and `@bazza-ui/filters` package together.

This can be done using the shadcn/ui registry:

```npm
npx shadcn@latest add {{REGISTRY_URL}}/r/filters{{RELEASE_CHANNEL}}
```

## Standalone

If you only want to install the filters engine, you can do so from the `npm` registry:

```npm
npm install @bazza-ui/filters{{RELEASE_CHANNEL}}
```
