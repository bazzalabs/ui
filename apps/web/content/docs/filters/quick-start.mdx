## Basic Example

Here's a minimal example to get you started with the filter system.

### 1. Define your column configurations

```ts title="columns.ts"
import { createColumnConfigHelper } from '@bazza-ui/filters'
import type { Issue } from './types'

const dtf = createColumnConfigHelper<Issue>()

export const columnsConfig = [
  dtf
    .text()
    .id('title')
    .accessor((row) => row.title)
    .displayName('Title')
    .build(),
  dtf
    .option()
    .accessor((row) => row.status.id)
    .id('status')
    .displayName('Status')
    .build(),
] as const
```

### 2. Create the filter instance

```tsx title="issues-table.tsx"
import { useDataTableFilters } from '@bazza-ui/filters'
import { Filter } from '@/components/filter'
import { columnsConfig } from './columns'

export function IssuesTable({ data }) {
  const { columns, filters, actions, strategy } = useDataTableFilters({
    strategy: 'client',
    data,
    columnsConfig,
  })

  return (
    <div>
      <Filter
        filters={filters}
        columns={columns}
        actions={actions}
        strategy={strategy}
      />
      {/* Your data table */}
    </div>
  )
}
```
