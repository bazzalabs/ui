A select component displays a trigger that opens a dropdown with selectable options. It's designed for single-value selection in forms, with support for search filtering, option groups, custom rendering, and native form integration.

## Installation

```bash
bun add @bazza-ui/react
```

## Anatomy

```tsx
<Select.Root>
  <Select.Trigger>
    <Select.Value />
    <Select.Icon />
  </Select.Trigger>
  <Select.Portal>
    <Select.Backdrop />
    <Select.Positioner>
      <Select.Popup>
        <Select.Arrow />
        <Select.Surface>
          <Select.Input />
          <Select.List>
            <Select.Group>
              <Select.GroupLabel />
              <Select.Item>
                <Select.ItemLabel />
                <Select.ItemIndicator />
              </Select.Item>
            </Select.Group>
            <Select.Separator />
            <Select.Empty />
          </Select.List>
        </Select.Surface>
        <Select.ScrollUpArrow />
        <Select.ScrollDownArrow />
      </Select.Popup>
    </Select.Positioner>
  </Select.Portal>
</Select.Root>
```

## Features

- **Single selection** - Designed for selecting one value from a list
- **Form integration** - Works with native forms and `FormData`
- **Search filtering** - Built-in typeahead with fuzzy matching
- **Groups** - Organize options into labeled groups
- **Align to trigger** - Option to align selected item with trigger (like native select)
- **Virtualized** - Support for virtualized lists with thousands of items
- **Controlled & Uncontrolled** - Works in both modes with `value` and `onValueChange`

## Guides

### Basics

Select provides a form control for selecting a single value from a list of options.

#### Controlled vs Uncontrolled

```tsx
// Uncontrolled - Select manages its own value
<Select.Root defaultValue="apple">
  ...
</Select.Root>

// Controlled - You manage the value
const [value, setValue] = React.useState('')

<Select.Root value={value} onValueChange={setValue}>
  ...
</Select.Root>
```

#### Multi-Select Mode

Enable multi-select with the `multiple` prop:

```tsx
const [values, setValues] = React.useState<string[]>([])

<Select.Root multiple values={values} onValuesChange={setValues}>
  ...
</Select.Root>
```

### Form Integration

Select integrates seamlessly with native HTML forms:

```tsx
<form onSubmit={handleSubmit}>
  <Select.Root name="priority" required>
    <Select.Trigger>
      <Select.Value placeholder="Select priority..." />
    </Select.Trigger>
    ...
  </Select.Root>
  <button type="submit">Submit</button>
</form>
```

**Form props:**
- `name` - Field name for FormData submission
- `form` - Associate with a form by ID
- `required` - Mark field as required

Hidden inputs are automatically rendered for form submission.

### Displaying Values

The `<Select.Value>` component displays the selected value or a placeholder:

```tsx
<Select.Trigger>
  <Select.Value placeholder="Select an option..." />
  <Select.Icon />
</Select.Trigger>
```

#### Using the Items Prop

For automatic label resolution, pass an `items` prop to Root:

```tsx
<Select.Root
  value={value}
  onValueChange={setValue}
  items={{
    us: 'United States',
    uk: 'United Kingdom',
    ca: 'Canada',
  }}
>
  <Select.Trigger>
    {/* Displays "United States" when value is "us" */}
    <Select.Value placeholder="Select country..." />
  </Select.Trigger>
  ...
</Select.Root>
```

The `items` prop accepts either a record or an array:

```tsx
// Record format
items={{ us: 'United States', uk: 'United Kingdom' }}

// Array format
items={[
  { value: 'us', label: 'United States' },
  { value: 'uk', label: 'United Kingdom' },
]}
```

### Virtualization

For selects with many options (100+), use virtualization:

```tsx
import { useVirtualizer } from '@tanstack/react-virtual'

const items = Array.from({ length: 1000 }, (_, i) => ({
  value: `item-${i}`,
  label: `Item ${i}`,
}))

function VirtualizedSelect() {
  const scrollRef = React.useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => scrollRef.current,
    estimateSize: () => 36,
  })

  return (
    <Select.Root
      virtualized
      virtualItems={items}
      onHighlightChange={(id, index) => {
        virtualizer.scrollToIndex(index, { align: 'auto' })
      }}
    >
      <Select.Trigger>
        <Select.Value placeholder="Select item..." />
      </Select.Trigger>
      <Select.Portal>
        <Select.Positioner>
          <Select.Popup>
            <Select.Surface filter={false}>
              <Select.List viewportRef={scrollRef}>
                <div style={{ height: virtualizer.getTotalSize() }}>
                  {virtualizer.getVirtualItems().map((row) => (
                    <div
                      key={row.key}
                      style={{
                        position: 'absolute',
                        top: row.start,
                        height: row.size,
                        width: '100%',
                      }}
                    >
                      <Select.Item value={items[row.index].value}>
                        <Select.ItemIndicator />
                        <Select.ItemLabel>{items[row.index].label}</Select.ItemLabel>
                      </Select.Item>
                    </div>
                  ))}
                </div>
              </Select.List>
            </Select.Surface>
          </Select.Popup>
        </Select.Positioner>
      </Select.Portal>
    </Select.Root>
  )
}
```

### Object Values

Select supports using objects as values instead of just strings. This is useful when working with complex data structures like database records or API responses.

#### Auto-detected `{ value, label }` Objects

If your objects have a `value` and `label` property, Select will automatically use them:

```tsx
interface Fruit {
  value: string
  label: string
}

const fruits: Fruit[] = [
  { value: 'apple', label: 'Apple' },
  { value: 'banana', label: 'Banana' },
  { value: 'cherry', label: 'Cherry' },
]

function ObjectSelect() {
  const [selected, setSelected] = React.useState<Fruit | null>(null)

  return (
    <Select.Root value={selected} onValueChange={setSelected}>
      <Select.Trigger>
        <Select.Value placeholder="Select a fruit..." />
      </Select.Trigger>
      <Select.Portal>
        <Select.Positioner>
          <Select.Popup>
            <Select.Surface>
              <Select.List>
                {fruits.map((fruit) => (
                  <Select.Item key={fruit.value} value={fruit}>
                    <Select.ItemIndicator />
                    <Select.ItemLabel />
                  </Select.Item>
                ))}
              </Select.List>
            </Select.Surface>
          </Select.Popup>
        </Select.Positioner>
      </Select.Portal>
    </Select.Root>
  )
}
```

- **Display**: Uses `label` property for `<Select.Value>` and `<Select.ItemLabel>`
- **Form submission**: Uses `value` property for hidden form inputs
- **Equality**: Uses reference equality by default

#### Custom Object Shapes

For objects with different shapes, use `isItemEqualToValue`, `itemToStringLabel`, and `itemToStringValue`:

```tsx
interface User {
  id: number
  firstName: string
  lastName: string
  email: string
}

const users: User[] = [
  { id: 1, firstName: 'John', lastName: 'Doe', email: 'john@example.com' },
  { id: 2, firstName: 'Jane', lastName: 'Smith', email: 'jane@example.com' },
]

function UserSelect() {
  const [selected, setSelected] = React.useState<User | null>(null)

  return (
    <Select.Root
      value={selected}
      onValueChange={setSelected}
      // Compare by ID instead of reference
      isItemEqualToValue={(item, value) => item.id === value.id}
      // Display full name
      itemToStringLabel={(user) => `${user.firstName} ${user.lastName}`}
      // Submit ID to form
      itemToStringValue={(user) => String(user.id)}
    >
      <Select.Trigger>
        <Select.Value placeholder="Select a user..." />
      </Select.Trigger>
      <Select.Portal>
        <Select.Positioner>
          <Select.Popup>
            <Select.Surface>
              <Select.List>
                {users.map((user) => (
                  <Select.Item key={user.id} value={user}>
                    <Select.ItemIndicator />
                    <Select.ItemLabel />
                  </Select.Item>
                ))}
              </Select.List>
            </Select.Surface>
          </Select.Popup>
        </Select.Positioner>
      </Select.Portal>
    </Select.Root>
  )
}
```

**Props explained:**

| Prop | Purpose | Example |
|------|---------|---------|
| `isItemEqualToValue` | Compare item to selected value | `(a, b) => a.id === b.id` |
| `itemToStringLabel` | Convert object to display string | `(u) => u.name` |
| `itemToStringValue` | Convert object for form submission | `(u) => String(u.id)` |

#### Multi-Select with Objects

Object values work with multi-select too:

```tsx
const [selected, setSelected] = React.useState<Fruit[]>([])

<Select.Root
  multiple
  values={selected}
  onValuesChange={setSelected}
>
  ...
</Select.Root>
```
