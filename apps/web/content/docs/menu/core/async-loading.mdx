# Async Loading

Menus support asynchronous data loading for dynamic content like searching, fetching user data, or loading large datasets.

## Topics to Cover

### Loader Functions
- Define async functions that return menu nodes
- Passed to `loader` property on submenu or root
- Called when submenu is opened or search query changes
- Can return `Promise<MenuNode[]>`

### React Query Integration
- Recommended for async loading
- Built-in support for React Query
- Automatic caching, refetching, and error handling
- Loading states managed automatically

### Basic Example
```tsx
const menu = {
  nodes: [
    {
      kind: 'submenu',
      id: 'users',
      label: 'Users',
      loader: async () => {
        const response = await fetch('/api/users')
        const users = await response.json()
        return users.map(user => ({
          kind: 'item',
          id: user.id,
          label: user.name
        }))
      }
    }
  ]
}
```

### With React Query
```tsx
import { useQuery } from '@tanstack/react-query'

function MyMenu() {
  const usersQuery = useQuery({
    queryKey: ['users'],
    queryFn: async () => {
      const response = await fetch('/api/users')
      return response.json()
    }
  })

  return (
    <Menu
      menu={{
        nodes: [
          {
            kind: 'submenu',
            id: 'users',
            label: 'Users',
            nodes: usersQuery.data?.map(user => ({
              kind: 'item',
              id: user.id,
              label: user.name
            })) || []
          }
        ]
      }}
    />
  )
}
```

- Show loading spinner/skeleton while loading
- Display error messages on failure
- Empty states when no results
- Handled automatically with React Query

### Example: Server-Side Search
```tsx
const menu = {
  nodes: [
    {
      kind: 'submenu',
      id: 'search',
      label: 'Search Products',
      loader: async ({ query }) => {
        if (!query) return []

        const response = await fetch(`/api/products?q=${query}`)
        const products = await response.json()

        return products.map(product => ({
          kind: 'item',
          id: product.id,
          label: product.name,
          description: product.category
        }))
      }
    }
  ]
}
```
