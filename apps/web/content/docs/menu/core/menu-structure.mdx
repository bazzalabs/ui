# Menu Structure

All bazza-ui menus use a declarative data structure built around a `nodes` array. This structure is shared across command menus, dropdown menus, and context menus, making it easy to learn once and use everywhere.

## MenuDef Type

The root menu object is called a `MenuDef` and has this shape:

```tsx
type MenuDef = {
  // Unique identifier for the menu
  id?: string

  // Array of menu nodes (items, groups, submenus)
  nodes: MenuNode[]

  // Default properties for all nodes
  defaults?: {
    item?: Partial<ItemNode>
    group?: Partial<GroupNode>
    submenu?: Partial<SubmenuNode>
  }
}
```

### Basic Example

```tsx
const menu = {
  id: 'main-menu',
  nodes: [
    { kind: 'item', id: 'action1', label: 'Action 1' },
    { kind: 'item', id: 'action2', label: 'Action 2' }
  ]
}
```

## Nodes Array

The `nodes` array is the heart of the menu structure. It contains an ordered list of menu nodes, which can be:

- **Items** - Clickable actions (button, checkbox, radio)
- **Groups** - Containers that organize items visually
- **Submenus** - Nested menus with their own nodes
- **Separators** - Visual dividers

Each node must have:
- `kind` - The node type ('item', 'group', 'submenu', 'separator')
- `id` - A unique identifier within the menu

```tsx
const menu = {
  nodes: [
    // Item
    {
      kind: 'item',
      id: 'copy',
      label: 'Copy'
    },

    // Group
    {
      kind: 'group',
      id: 'edit-group',
      heading: 'Edit',
      nodes: [
        { kind: 'item', id: 'cut', label: 'Cut' },
        { kind: 'item', id: 'paste', label: 'Paste' }
      ]
    },

    // Submenu
    {
      kind: 'submenu',
      id: 'export',
      label: 'Export',
      nodes: [
        { kind: 'item', id: 'pdf', label: 'PDF' },
        { kind: 'item', id: 'csv', label: 'CSV' }
      ]
    },

    // Separator
    {
      kind: 'separator',
      id: 'sep1'
    }
  ]
}
```

## Nesting Structure

Menus support unlimited nesting depth through `groups` and `submenus`. Both have a `nodes` array that can contain any type of node.

### Groups with Nested Items

```tsx
{
  kind: 'group',
  id: 'file-group',
  heading: 'File',
  nodes: [
    { kind: 'item', id: 'new', label: 'New File' },
    { kind: 'item', id: 'open', label: 'Open File' },
    { kind: 'separator', id: 'sep1' },
    { kind: 'item', id: 'save', label: 'Save' }
  ]
}
```

### Submenus with Multiple Levels

```tsx
{
  kind: 'submenu',
  id: 'export',
  label: 'Export',
  nodes: [
    {
      kind: 'submenu',
      id: 'export-document',
      label: 'Document',
      nodes: [
        { kind: 'item', id: 'pdf', label: 'PDF' },
        { kind: 'item', id: 'docx', label: 'Word' }
      ]
    },
    {
      kind: 'submenu',
      id: 'export-data',
      label: 'Data',
      nodes: [
        { kind: 'item', id: 'csv', label: 'CSV' },
        { kind: 'item', id: 'json', label: 'JSON' }
      ]
    }
  ]
}
```

## Real-World Example

Here's a complete menu with all node types:

```tsx
const menu = {
  id: 'editor-menu',
  defaults: {
    item: {
      onSelect: ({ node }) => console.log('Selected:', node.id)
    }
  },
  nodes: [
    // Simple items
    {
      kind: 'item',
      id: 'undo',
      label: 'Undo',
      icon: <UndoIcon />
    },
    {
      kind: 'item',
      id: 'redo',
      label: 'Redo',
      icon: <RedoIcon />
    },

    { kind: 'separator', id: 'sep1' },

    // Group with items
    {
      kind: 'group',
      id: 'edit-group',
      heading: 'Edit',
      nodes: [
        {
          kind: 'item',
          id: 'cut',
          label: 'Cut',
          icon: <ScissorsIcon />
        },
        {
          kind: 'item',
          id: 'copy',
          label: 'Copy',
          icon: <CopyIcon />
        },
        {
          kind: 'item',
          id: 'paste',
          label: 'Paste',
          icon: <ClipboardIcon />
        }
      ]
    },

    { kind: 'separator', id: 'sep2' },

    // Submenu with nested content
    {
      kind: 'submenu',
      id: 'export',
      label: 'Export',
      icon: <DownloadIcon />,
      nodes: [
        {
          kind: 'group',
          id: 'formats',
          heading: 'Document Formats',
          nodes: [
            { kind: 'item', id: 'pdf', label: 'PDF' },
            { kind: 'item', id: 'docx', label: 'Word Document' },
            { kind: 'item', id: 'html', label: 'HTML' }
          ]
        },
        {
          kind: 'group',
          id: 'data-formats',
          heading: 'Data Formats',
          nodes: [
            { kind: 'item', id: 'csv', label: 'CSV' },
            { kind: 'item', id: 'json', label: 'JSON' }
          ]
        }
      ]
    }
  ]
}
```

## Node IDs

Every node requires a unique `id` within the menu. IDs are used for:

- **Keyboard navigation** - Tracking the active/focused item
- **State management** - Checkbox/radio selections
- **Analytics** - Tracking which actions users take
- **Debugging** - Identifying nodes in dev tools

### ID Best Practices

```tsx
// ✅ Good - descriptive and unique
{ kind: 'item', id: 'edit-profile', label: 'Edit Profile' }
{ kind: 'item', id: 'delete-account', label: 'Delete Account' }

// ❌ Bad - not unique
{ kind: 'item', id: 'item', label: 'Edit Profile' }
{ kind: 'item', id: 'item', label: 'Delete Account' }

// ❌ Bad - not descriptive
{ kind: 'item', id: '1', label: 'Edit Profile' }
{ kind: 'item', id: '2', label: 'Delete Account' }
```

## Defaults

The `defaults` object lets you set default properties for all nodes of a given type. This is useful for:

- Setting a common `onSelect` handler
- Adding default styling
- Configuring behavior for all items

```tsx
const menu = {
  defaults: {
    // All items get this onSelect unless overridden
    item: {
      onSelect: ({ node }) => {
        console.log('Selected:', node.label)
        analytics.track('menu_item_selected', { id: node.id })
      }
    },

    // All groups get this className
    group: {
      className: 'my-custom-group-style'
    }
  },
  nodes: [
    // Uses default onSelect
    { kind: 'item', id: 'action1', label: 'Action 1' },

    // Overrides default onSelect
    {
      kind: 'item',
      id: 'action2',
      label: 'Action 2',
      onSelect: () => console.log('Custom handler!')
    }
  ]
}
```

## Dynamic Menus

Menus can be built dynamically from data:

```tsx
// From static data
const actions = ['Copy', 'Cut', 'Paste']
const menu = {
  nodes: actions.map(action => ({
    kind: 'item',
    id: action.toLowerCase(),
    label: action
  }))
}

// From API response
const menu = {
  nodes: userData.permissions.map(permission => ({
    kind: 'item',
    id: permission.id,
    label: permission.name,
    disabled: !permission.enabled
  }))
}

// From grouped data
const categories = [
  { name: 'Fruits', items: ['Apple', 'Banana'] },
  { name: 'Vegetables', items: ['Carrot', 'Broccoli'] }
]

const menu = {
  nodes: categories.map(category => ({
    kind: 'group',
    id: category.name.toLowerCase(),
    heading: category.name,
    nodes: category.items.map(item => ({
      kind: 'item',
      id: item.toLowerCase(),
      label: item
    }))
  }))
}
```

## TypeScript Support

All menu structures are fully typed:

```tsx
import type { MenuDef, MenuNode } from '@bazza-ui/menu'

const menu: MenuDef = {
  id: 'my-menu',
  nodes: [
    // TypeScript ensures correct node structure
    { kind: 'item', id: 'action', label: 'Action' }
  ]
}

// Individual node types
import type { ItemNode, GroupNode, SubmenuNode } from '@bazza-ui/menu'

const item: ItemNode = {
  kind: 'item',
  id: 'copy',
  label: 'Copy',
  onSelect: () => {}
}
```
