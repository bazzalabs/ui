# Separators

Separators are visual dividers that create clear sections within menus.

## Topics to Cover

### Basic Separator
- `kind: 'separator'` node type
- Required: `id`
- No other properties needed

### Example
```tsx
const menu = {
  nodes: [
    { kind: 'item', id: 'copy', label: 'Copy' },
    { kind: 'item', id: 'paste', label: 'Paste' },
    { kind: 'separator', id: 'sep1' },
    { kind: 'item', id: 'delete', label: 'Delete' }
  ]
}
```

### Use Cases
- Separate dangerous actions (like Delete)
- Group related functionality visually
- Create visual breaks in long menus
- Separate groups when not using explicit groups

### Separators in Groups
- Can be used within group nodes
- Useful for sub-categorizing within a group

### Best Practices
- Don't overuse (creates visual noise)
- Place before/after important actions
- Use groups with headings instead if categories need labels
