The **menu surface** is the main container that holds all the menu components.

-----

The **menu input** is used to search/filter menu nodes in the surface (and descendant submenus, too, via deep search).

It always remains focused, even during keyboard navigation, clicks, and other interactions.

---

The **menu list** is the main container for menu nodes.

It is a scrollable element and can contain items, submenu triggers, and other nodes.

-----

The **menu header** and **menu footer** are optional components that can be used to provide additional information or actions related to the menu.
