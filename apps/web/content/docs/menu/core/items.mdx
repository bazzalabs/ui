# Items

Items are the primary interactive elements in menus. They represent actions users can take and come in three variants: button, checkbox, and radio.

## Button Items

The default item variant is a button - a clickable action that triggers an `onSelect` callback.

### Basic Button Item

```tsx
{
  kind: 'item',
  id: 'copy',
  label: 'Copy',
  onSelect: () => {
    // Handle action
    copyToClipboard()
  }
}
```

### With Icons

```tsx
import { CopyIcon, TrashIcon, EditIcon } from 'lucide-react'

const menu = {
  nodes: [
    {
      kind: 'item',
      id: 'copy',
      label: 'Copy',
      icon: <CopyIcon />,
      onSelect: () => copyToClipboard()
    },
    {
      kind: 'item',
      id: 'delete',
      label: 'Delete',
      icon: <TrashIcon />,
      onSelect: () => deleteItem()
    }
  ]
}
```

### With Descriptions

```tsx
{
  kind: 'item',
  id: 'export-pdf',
  label: 'Export as PDF',
  description: 'Download your document as a PDF file',
  icon: <DownloadIcon />,
  onSelect: () => exportAsPDF()
}
```

### Disabled Items

```tsx
{
  kind: 'item',
  id: 'paste',
  label: 'Paste',
  icon: <ClipboardIcon />,
  disabled: !hasClipboardContent, // Conditionally disable
  onSelect: () => paste()
}
```

## Checkbox Items

Checkbox items represent toggleable boolean state. They show a checkmark when `checked` is true.

### Basic Checkbox

```tsx
import { useState } from 'react'

function MyMenu() {
  const [notifications, setNotifications] = useState(true)

  return (
    <Menu
      menu={{
        nodes: [
          {
            kind: 'item',
            variant: 'checkbox',
            id: 'notifications',
            label: 'Enable Notifications',
            checked: notifications,
            onCheckedChange: (checked) => setNotifications(checked)
          }
        ]
      }}
    />
  )
}
```

### Multiple Checkboxes

```tsx
import { useState } from 'react'

function SettingsMenu() {
  const [settings, setSettings] = useState({
    notifications: true,
    autoSave: false,
    darkMode: true
  })

  const toggle = (key: string) => {
    setSettings(prev => ({ ...prev, [key]: !prev[key] }))
  }

  return (
    <Menu
      menu={{
        nodes: [
          {
            kind: 'item',
            variant: 'checkbox',
            id: 'notifications',
            label: 'Notifications',
            checked: settings.notifications,
            onCheckedChange: () => toggle('notifications')
          },
          {
            kind: 'item',
            variant: 'checkbox',
            id: 'auto-save',
            label: 'Auto Save',
            checked: settings.autoSave,
            onCheckedChange: () => toggle('autoSave')
          },
          {
            kind: 'item',
            variant: 'checkbox',
            id: 'dark-mode',
            label: 'Dark Mode',
            checked: settings.darkMode,
            onCheckedChange: () => toggle('darkMode')
          }
        ]
      }}
    />
  )
}
```

### Disabled Checkboxes

```tsx
{
  kind: 'item',
  variant: 'checkbox',
  id: 'premium-feature',
  label: 'Premium Feature',
  checked: false,
  disabled: !user.isPremium, // Only available for premium users
  onCheckedChange: (checked) => toggleFeature(checked)
}
```

## Radio Items

Radio items represent mutually exclusive selections within a radio group. Only one radio item can be selected at a time within its group.

**Note:** Radio items must be used inside a [radio group](/docs/menu/groups#radio-groups).

### Basic Radio Item

```tsx
import { useState } from 'react'

function ThemeMenu() {
  const [theme, setTheme] = useState('light')

  return (
    <Menu
      menu={{
        nodes: [
          {
            kind: 'group',
            variant: 'radio',
            id: 'theme-group',
            value: theme,
            onValueChange: setTheme,
            nodes: [
              {
                kind: 'item',
                variant: 'radio',
                id: 'light',
                label: 'Light Theme'
              },
              {
                kind: 'item',
                variant: 'radio',
                id: 'dark',
                label: 'Dark Theme'
              },
              {
                kind: 'item',
                variant: 'radio',
                id: 'system',
                label: 'System Theme'
              }
            ]
          }
        ]
      }}
    />
  )
}
```

### With Icons and Descriptions

```tsx
import { SunIcon, MoonIcon, LaptopIcon } from 'lucide-react'

const menu = {
  nodes: [
    {
      kind: 'group',
      variant: 'radio',
      id: 'theme-group',
      heading: 'Appearance',
      value: theme,
      onValueChange: setTheme,
      nodes: [
        {
          kind: 'item',
          variant: 'radio',
          id: 'light',
          label: 'Light',
          description: 'Light color scheme',
          icon: <SunIcon />
        },
        {
          kind: 'item',
          variant: 'radio',
          id: 'dark',
          label: 'Dark',
          description: 'Dark color scheme',
          icon: <MoonIcon />
        },
        {
          kind: 'item',
          variant: 'radio',
          id: 'system',
          label: 'System',
          description: 'Match system settings',
          icon: <LaptopIcon />
        }
      ]
    }
  ]
}
```

## Item Properties

All item variants share these common properties:

### Required Properties

```tsx
{
  kind: 'item',          // Required: Identifies this as an item
  id: 'unique-id',       // Required: Unique identifier
  label: 'Label Text'    // Required: Display text
}
```

### Optional Properties

```tsx
{
  kind: 'item',
  id: 'example',
  label: 'Example Item',

  // Visual
  icon: <IconComponent />,           // Icon element (left side)
  description: 'Helper text',        // Subtitle/description
  className: 'custom-class',         // Additional CSS class

  // Behavior
  disabled: boolean,                 // Disable the item
  closeOnSelect: boolean,            // Close menu on select (default: true)
  keywords: ['search', 'terms'],     // Search keywords

  // Callbacks (button variant)
  onSelect: (context) => {},         // Click handler

  // Checkbox specific
  variant: 'checkbox',
  checked: boolean,                  // Checked state
  onCheckedChange: (checked) => {},  // Toggle handler

  // Radio specific
  variant: 'radio',
  // checked state comes from parent radio group
}
```

## onSelect Context

The `onSelect` callback receives a context object:

```tsx
{
  kind: 'item',
  id: 'example',
  label: 'Example',
  onSelect: (context) => {
    context.node      // The item node that was selected
    context.event     // The DOM event that triggered selection
    context.close()   // Function to close the menu
  }
}
```

### Example Usage

```tsx
{
  kind: 'item',
  id: 'copy',
  label: 'Copy',
  onSelect: ({ node, close }) => {
    copyToClipboard(node.id)
    toast.success(`Copied ${node.label}`)
    close() // Manually close the menu
  },
  closeOnSelect: false // Prevent automatic close
}
```

## Close Behavior

By default, selecting a button item closes the menu. You can control this:

```tsx
// Auto-close (default)
{
  kind: 'item',
  id: 'save',
  label: 'Save',
  onSelect: () => save()
  // Menu closes automatically
}

// Prevent auto-close
{
  kind: 'item',
  id: 'save-continue',
  label: 'Save and Continue',
  closeOnSelect: false,
  onSelect: () => {
    save()
    // Menu stays open
  }
}

// Manual close control
{
  kind: 'item',
  id: 'conditional',
  label: 'Conditional Action',
  closeOnSelect: false,
  onSelect: ({ close }) => {
    const success = performAction()
    if (success) {
      close() // Close only on success
    }
  }
}
```

## Keyboard Shortcuts

Items can display keyboard shortcut hints (visual only, not functional):

```tsx
{
  kind: 'item',
  id: 'save',
  label: 'Save',
  shortcut: '⌘S',  // Display shortcut hint
  onSelect: () => save()
}
```

**Note:** This only displays the shortcut. You need to handle the actual keyboard event separately (see [Keyboard Navigation](/docs/menu/keyboard-navigation)).

## Best Practices

### Descriptive Labels

```tsx
// ✅ Good - clear action
{ label: 'Delete Account' }
{ label: 'Export as PDF' }

// ❌ Bad - vague
{ label: 'Delete' }
{ label: 'Export' }
```

### Appropriate Icons

```tsx
// ✅ Good - icon matches action
{ label: 'Copy', icon: <CopyIcon /> }
{ label: 'Delete', icon: <TrashIcon /> }

// ❌ Bad - confusing icon
{ label: 'Copy', icon: <TrashIcon /> }
```

### Disabled State

```tsx
// ✅ Good - conditional disable with reason
{
  label: 'Paste',
  disabled: !clipboardHasContent,
  description: clipboardHasContent ? undefined : 'Nothing to paste'
}

// ❌ Bad - always disabled
{
  label: 'Paste',
  disabled: true
}
```

### Use Correct Variant

```tsx
// ✅ Good - checkbox for toggles
{ variant: 'checkbox', label: 'Enable Notifications' }

// ❌ Bad - button for toggle state
{ label: notifications ? 'Disable Notifications' : 'Enable Notifications' }

// ✅ Good - radio for exclusive selection
{ variant: 'radio', label: 'Light Theme' }

// ❌ Bad - multiple buttons with state
{ label: theme === 'light' ? '✓ Light' : 'Light' }
```
