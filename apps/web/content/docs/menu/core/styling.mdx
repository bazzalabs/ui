# Styling

All bazza-ui menus provide flexible styling through data attributes, CSS variables, slots, and class names.

## Topics to Cover

### Data Attributes
- All menu elements have `data-*` attributes for styling
- `data-kind`: Node type (item, group, submenu, separator)
- `data-variant`: Item variant (button, checkbox, radio)
- `data-disabled`: When item is disabled
- `data-active`: When item is selected/active
- `data-checked`: When checkbox/radio is checked
- `data-highlighted`: When item is highlighted/focused

### Example Data Attribute Styling
```css
/* Style all items */
[data-kind="item"] {
  padding: 8px 12px;
}

/* Style disabled items */
[data-disabled="true"] {
  opacity: 0.5;
  cursor: not-allowed;
}

/* Style active/highlighted items */
[data-highlighted="true"] {
  background-color: var(--menu-item-bg-hover);
}

/* Style checked items */
[data-checked="true"] {
  color: var(--menu-item-color-checked);
}
```

### CSS Variables
- Menu components expose CSS variables
- Customize colors, spacing, typography
- Scope to menu instance or globally
- Examples: `--menu-bg`, `--menu-item-bg`, `--menu-border-radius`

### Class Names
- Add custom classes via `className` prop
- Apply to individual nodes or entire menu
- Works with Tailwind, CSS Modules, etc.

### Slots System (Advanced)
- Override rendering of specific parts
- `slots` prop: Replace default components
- `slotProps` prop: Pass props to slot components
- Example: Custom item renderer, custom checkbox indicator

### Example: Tailwind Styling
```tsx
const menu = {
  className: 'bg-white dark:bg-gray-900 border shadow-lg',
  nodes: [
    {
      kind: 'item',
      id: 'copy',
      label: 'Copy',
      className: 'hover:bg-blue-50 dark:hover:bg-blue-900'
    }
  ]
}
```

### Example: CSS Variables
```tsx
<Menu
  menu={menu}
  style={{
    '--menu-bg': '#ffffff',
    '--menu-item-bg-hover': '#f3f4f6',
    '--menu-border-radius': '8px'
  }}
/>
```

### Theming Best Practices
- Use data attributes for state-based styling
- Use CSS variables for color themes
- Use className for layout/spacing
- Don't override internal structure (breaks accessibility)

### Dark Mode Support
- CSS variables adapt to dark mode
- Use `dark:` classes with Tailwind
- Prefer semantic color tokens

### Component-Specific Styling
- Command Menu: Modal dialog styles
- Dropdown Menu: Popover positioning, z-index
- Context Menu: Same as dropdown

### Registry vs NPM Styling
- Registry version: Pre-styled with shadcn/ui
- NPM version: Unstyled primitive (bring your own styles)
- Both use same data attributes
