Groups are used to logically organize menu nodes together.

An optional `heading` can also be passed to render a visible heading above the group.

We can use the `nodes` property to specify the group's contents. A group can contain item and submenu nodes. **Groups cannot be nested.**

## Variants

### Default

The `default` variant is, as you would suspect, the default variant applied to groups if left unspecified.

This variant acts as a "display" group; grouping nodes is simply a way to visually group related items/submenus together.

No additional functionality is provided by this variant.

### Radio

> [!NOTE] Note that `value` and `onValueChange` are required properties - radio groups cannot be used in an uncontrolled fashion.

We can create radio groups by passing `value` and `onValueChange` to a group with the `'radio'` variant.

Child item nodes must specify the `'radio'` variant as well. They can also specify a `value` property if desired (if unspecified, the node's `id` will be used as the value).
