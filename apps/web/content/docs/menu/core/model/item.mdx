The **item node** is a fundamental building block of the menu system.

It represents a single option or action within the menu structure. Each item can have a label and an icon, which are displayed to the user.

When an item is triggered, it performs a specific action.

## Common Properties

| Property | Type | Description |
| --- | --- | --- |
| label | string | The text label displayed for the item |
| icon | string | The icon displayed for the item |
| action | function | The action to perform when the item is triggered |
