You can build menus in bazza/ui using nodes, a high-level abstraction that allows you to define menu structures declaratively.

Nodes provide a flexible and intuitive way to create menus by organizing items into a hierarchical structure.

## Definitions vs. Instances

When you're building your menus, you'll almost always define them as **node definitions** (`NodeDef`).

At runtime, we take your node definitions and convert them into **node instances** (`Node`), or **nodes** for short. This process adds additional properties, accessors, and references to your node definitions.

## Kinds

We specify the **kind** of a node using the `kind` property. It changes the behavior of the node and determines how it is rendered.
