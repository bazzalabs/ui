This is where everything starts. Every menu starts at the root.

## Basics

Every menu needs an `id` to uniquely identify the node from others in the node tree.

We can specify the contents of the menu with `nodes`, which is an array of node definitions.

## State

To used controlled state for the root menu's `open` or `input` states, we can pass a `StateDescriptor` object, defined below:

```typescript
export type StateDescriptor<T> = {
  value: T
  onValueChange: React.Dispatch<React.SetStateAction<T>>
  defaultValue?: T
}
```

For example, to control the `open` and `input` states of a menu:

```typescript
const [open, setOpen] = React.useState(false);
const [search, setSearch] = React.useState('');

const menu: MenuDef = {
  id: 'root',
  open: {
    value: open,
    onValueChange: setOpen
  },
  input: {
    value: search,
    onValueChange: setSearch
  },
  nodes: []
}
```

## Input

We can control the visibility behaviour of the input field using the `hideSearchUntilActive` prop (`false` by default).

When `true`, the input field will be hidden until the user starts typing.

This allows us to mimic the look of a `select` element, while retaining the powerful search functionality when you need it.
