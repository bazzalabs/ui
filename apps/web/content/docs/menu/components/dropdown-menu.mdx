# Dropdown Menu

A button-triggered menu that opens as a popover. Submenus appear as nested popovers positioned adjacent to the parent.

## Installation

### Registry (Recommended)
```bash
npx shadcn@latest add https://ui.bazza.dev/r/dropdown-menu
```

### NPM Package
```bash
npm install @bazza-ui/dropdown-menu @bazza-ui/menu
```

## Quick Start

```tsx
import { DropdownMenu } from '@bazza-ui/dropdown-menu'

function App() {
  return (
    <DropdownMenu
      trigger={<button>Actions</button>}
      menu={{
        nodes: [
          {
            kind: 'item',
            id: 'edit',
            label: 'Edit',
            onSelect: () => console.log('Edit')
          }
        ]
      }}
    />
  )
}
```

## Topics to Cover

### Unique Features
- **Button Trigger**: Attached to a clickable element
- **Popover Positioning**: Positioned relative to trigger button
- **Nested Popovers**: Submenus open as adjacent popovers
- **Alignment Options**: Control how menu aligns with trigger
- **Collision Detection**: Auto-adjusts to stay in viewport

### Trigger Mechanism
- `trigger` prop: Pass a button or clickable element
- Click to open/close
- `asChild` pattern for custom triggers
- Controlled/uncontrolled modes

### Positioning
- `side`: 'top' | 'right' | 'bottom' | 'left' (default: 'bottom')
- `align`: 'start' | 'center' | 'end' (default: 'start')
- `sideOffset`: Distance from trigger (px)
- `alignOffset`: Alignment offset (px)

### Compound Components
- `DropdownMenuRoot`: Context provider
- `DropdownMenu.Trigger`: Trigger button
- `DropdownMenu.Content`: Menu content/items
- `DropdownMenu.Item`: Individual items
- `DropdownMenu.Group`: Group container
- `DropdownMenu.Separator`: Separator

### Example: Positioned Menu
```tsx
<DropdownMenu
  trigger={<Button>Open Menu</Button>}
  side="bottom"
  align="end"
  sideOffset={8}
  menu={{
    nodes: [
      { kind: 'item', id: 'copy', label: 'Copy' },
      { kind: 'item', id: 'paste', label: 'Paste' }
    ]
  }}
/>
```

### Example: Nested Submenus
```tsx
<DropdownMenu
  trigger={<Button>File</Button>}
  menu={{
    nodes: [
      {
        kind: 'submenu',
        id: 'export',
        label: 'Export',
        nodes: [
          {
            kind: 'submenu',
            id: 'document',
            label: 'Document',
            nodes: [
              { kind: 'item', id: 'pdf', label: 'PDF' },
              { kind: 'item', id: 'docx', label: 'Word' }
            ]
          }
        ]
      }
    ]
  }}
/>
```

### Controlled vs Uncontrolled
- Uncontrolled: Menu manages own open state
- Controlled: Pass `open` and `onOpenChange` props
- Useful for programmatic control

### Modal vs Non-Modal
- Non-modal by default (can interact with page)
- `modal` prop: Makes menu modal (blocks page interaction)

### Close Behavior
- Click outside to close
- Escape key to close
- Select item closes by default (configurable)
- `closeOnSelect` per item

### Use Cases
- Action menus (Edit, Delete, Share)
- User profile menus
- Settings menus
- Context-specific actions
- More options (...) menus

### Comparison with Context Menu
| Feature | Dropdown | Context |
|---------|----------|---------|
| Trigger | Button click | Right-click |
| Position | Relative to button | At cursor |
| Use Case | Button actions | Contextual actions |
