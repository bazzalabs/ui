# Context Menu

A right-click triggered menu that appears at the cursor position. Uses a virtual anchor for positioning.

## Installation

### Registry (Recommended)
```bash
npx shadcn@latest add https://ui.bazza.dev/r/context-menu
```

### NPM Package
```bash
npm install @bazza-ui/context-menu @bazza-ui/menu
```

## Quick Start

```tsx
import { ContextMenu } from '@bazza-ui/context-menu'

function App() {
  return (
    <ContextMenu
      menu={{
        nodes: [
          {
            kind: 'item',
            id: 'copy',
            label: 'Copy',
            onSelect: () => console.log('Copy')
          }
        ]
      }}
    >
      <div>Right-click me</div>
    </ContextMenu>
  )
}
```

## Topics to Cover

### Unique Features
- **Right-Click Trigger**: Opens on right-click (contextmenu event)
- **Cursor Positioning**: Appears at cursor location (virtual anchor)
- **Long-Press on Mobile**: Touch long-press support
- **Area-Based**: Wraps content area that triggers menu
- **Nested Popovers**: Like dropdown, submenus are adjacent popovers

### Trigger Mechanism
- Right-click (desktop)
- Long-press (mobile/touch)
- `onContextMenu` event
- Prevents default browser context menu

### Virtual Anchor Positioning
- No physical trigger element
- Positioned at cursor coordinates
- Uses Floating UI virtual element
- Smart collision detection

### Long-Press Support
- Configurable duration (default: 500ms)
- Touch-friendly
- Visual feedback during press
- Cancels on move/lift

### Wrapping Content
- Wrap target area with `<ContextMenu>`
- Children become the trigger area
- Can wrap text, images, canvas, etc.
- Supports any content type

### Example: With Submenus
```tsx
<ContextMenu
  menu={{
    nodes: [
      {
        kind: 'submenu',
        id: 'share',
        label: 'Share',
        nodes: [
          { kind: 'item', id: 'email', label: 'Email' },
          { kind: 'item', id: 'link', label: 'Copy Link' }
        ]
      },
      { kind: 'separator', id: 'sep1' },
      { kind: 'item', id: 'delete', label: 'Delete' }
    ]
  }}
>
  <div className="p-8 border rounded">
    Right-click this area
  </div>
</ContextMenu>
```

### Example: Canvas/Image Context Menu
```tsx
<ContextMenu
  menu={{
    nodes: [
      { kind: 'item', id: 'save', label: 'Save Image' },
      { kind: 'item', id: 'copy', label: 'Copy Image' },
      { kind: 'separator', id: 'sep1' },
      { kind: 'item', id: 'properties', label: 'Properties' }
    ]
  }}
>
  <img src="/image.jpg" alt="Right-click me" />
</ContextMenu>
```

### Preventing Default
- Automatically prevents browser context menu
- Custom preventDefault handling
- Allow selective browser menu

### Mobile Considerations
- Long-press duration configuration
- Touch event handling
- Visual feedback (ripple/highlight)
- Accessibility with touch

### Use Cases
- File explorer context menus
- Image/media context actions
- Text selection menus
- Canvas/drawing app menus
- Grid/table row actions
- Right-click anywhere features

### Comparison with Dropdown
| Feature | Context | Dropdown |
|---------|---------|----------|
| Trigger | Right-click | Button click |
| Position | At cursor | Relative to button |
| Anchor | Virtual | Physical element |
| Use Case | Area actions | Button actions |
