## Backdrop

An overlay beneath the popup. Pressing down on it closes the menu at once, as outside presses do for the other menus. Call `event.preventDefault()` in your own `onPointerDown` to opt out. Renders a `<div>` element.

## Header

Container for tabbable content at the top of a surface, such as toolbars or quick actions. Registers as a focus zone: its tabbable children join the surface's Tab cycle. Renders a `<div>` element.

<TypeTableAuto type="CommandMenuHeaderProps" pkg="@bazza-ui/react" />

## Footer

Container for tabbable content at the bottom of a surface, such as action rows. Registers as a focus zone: its tabbable children join the surface's Tab cycle. Renders a `<div>` element.

<TypeTableAuto type="CommandMenuFooterProps" pkg="@bazza-ui/react" />

## FocusZone

Declares its children as tabbable popup content, so they join the surface's Tab cycle. A zone with no tabbable children is treated as absent. Renders a `<div>` element.

<TypeTableAuto type="CommandMenuFocusZoneProps" pkg="@bazza-ui/react" />

## CheckboxGroupValue

Headless provider for checkbox group state: the same `value` / `onValueChange` contract as `CheckboxGroup` without rendering an element. Rows of a `CheckboxGroupDef` read their state from the def and need no provider from you.

<TypeTableAuto type="CommandMenuCheckboxGroupValueProps" pkg="@bazza-ui/react" />

## Subpage

Groups the parts of one page in a multi-step flow. Link it to its trigger with a shared `pageId`. Escape closes the whole menu from a subpage by default. Doesn't render its own HTML element.

## Data-First API

Instead of writing rows as JSX, you can pass them to `Surface` as data. Data-first content supports deep search across subpages and async results.

### useDataList

Reads the list computed by a `List` inside a data `Surface`: the visible nodes, the node renderer, the result count and the async state.

<TypeTableAuto type="DataListChildrenState" pkg="@bazza-ui/react" />

### DeepSearchConfig

Configures `Surface`'s `deepSearch`, which searches the rows inside subpages from the root input.
