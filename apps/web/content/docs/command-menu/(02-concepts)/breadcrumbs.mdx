# Breadcrumbs

Breadcrumbs provide visual feedback about the current navigation state in paged command menus. They show where you are in the menu hierarchy and provide a quick way to navigate back to parent menus.

## Overview

Breadcrumbs in command menus consist of:

- **Back button** - Navigate to the parent menu
- **Breadcrumb trail** - Show the path from root to current menu
- **Separators** - Visual separators between breadcrumb items

```
← Back / Settings / Advanced Settings
[Button] [Item 1] [Sep] [Item 2]
```

## Anatomy

### Back Button

The back button always appears when in a submenu:

```tsx
<button onClick={popSubmenu} className={backButtonClassName}>
  <ChevronLeft /> {/* or your custom icon */}
  Back
</button>
```

**Interactions:**
- Click to navigate to parent menu
- Also triggered by Escape or Left arrow key

### Breadcrumb Trail

Shows the path from root to current position:

```
Home / Settings / Advanced / API
[Root implied] [Level 1] [Level 2] [Level 3]
```

Each item displays the `menuTitle` (or `menuId` as fallback) from the navigation stack entry.

### Separators

Visual separators between breadcrumb items (typically `/`):

```tsx
<span className={breadcrumbSeparatorClassName}>/</span>
```

## When Breadcrumbs Appear

Breadcrumbs are shown when:

1. `showBreadcrumbs` prop is `true` (default)
2. Navigation stack is not empty (`isInSubmenu` is `true`)

```tsx
// ✅ Breadcrumbs shown (default)
<CommandMenu menu={menu} />

// ✅ Breadcrumbs shown (explicit)
<CommandMenu menu={menu} showBreadcrumbs={true} />

// ❌ Breadcrumbs hidden
<CommandMenu menu={menu} showBreadcrumbs={false} />
```

## Breadcrumb Content

### Navigation Stack Entry

Each breadcrumb corresponds to a navigation stack entry:

```typescript
type NavigationStackEntry = {
  menuId: string        // Used as fallback if no title
  menuTitle?: string    // Displayed in breadcrumb
  parentMenuId?: string // Parent reference
}
```

### Title vs Label

Submenus have both `label` (shown in parent menu) and `title` (shown in breadcrumbs):

```tsx
{
  kind: 'submenu',
  id: 'settings',
  label: 'Settings',              // Shows in parent menu list
  title: 'Settings Menu',         // Shows in breadcrumbs
  nodes: [...]
}
```

**Best practice:** Use `title` to provide clearer context:

```tsx
// ❌ Not helpful in breadcrumbs
{
  label: 'Advanced',
  title: 'Advanced'
}

// ✅ Better context
{
  label: 'Advanced',
  title: 'Advanced Settings'
}
```

## Styling Breadcrumbs

### Using classNames

```tsx
<CommandMenu
  menu={menu}
  theme={{
    classNames: {
      breadcrumbs: 'border-b border-gray-200 px-4 py-2',
      breadcrumbItem: 'text-sm text-gray-600',
      breadcrumbSeparator: 'mx-2 text-gray-400',
      backButton: 'text-sm font-medium hover:text-blue-600 transition-colors',
    },
  }}
/>
```

### Available Class Names

| Key | Element | Description |
|-----|---------|-------------|
| `breadcrumbs` | Container | Wrapper div for entire breadcrumb UI |
| `backButton` | Back button | Button to navigate to parent |
| `breadcrumbItem` | Breadcrumb text | Individual breadcrumb label |
| `breadcrumbSeparator` | Separator | Visual separator (typically `/`) |

### Data Attributes

Target breadcrumbs with CSS using data attributes:

```css
/* Breadcrumb container */
[data-command-menu-breadcrumbs] {
  /* Your styles */
}

/* Back button */
[data-command-menu-back-button] {
  /* Your styles */
}

/* Individual breadcrumb */
[data-command-menu-breadcrumb-item] {
  /* Your styles */
}
```

## Custom Back Button

While there's no slot for the back button, you can style it extensively:

```tsx
theme={{
  classNames: {
    backButton: cn(
      'flex items-center gap-1',
      'text-sm font-medium text-muted-foreground',
      'hover:text-foreground',
      'transition-colors duration-150',
      'cursor-pointer'
    ),
  },
}}
```

The back button automatically includes:
- Chevron icon
- "Back" text
- Click handler
- Keyboard navigation (Escape, Left arrow)

## Hiding Breadcrumbs

You might want to hide breadcrumbs if:

1. **Custom navigation UI** - You're building your own breadcrumb system
2. **Space constraints** - Mobile or compact layouts
3. **Single-level menu** - No submenus in your menu definition

```tsx
<CommandMenu
  menu={menu}
  showBreadcrumbs={false}
/>
```

When hidden, users can still navigate back using:
- Escape key
- Left arrow key (when in submenu)

## External Breadcrumbs

Build custom breadcrumbs outside the dialog using `onNavigationChange`:

```tsx
function CustomBreadcrumbs() {
  const [breadcrumbs, setBreadcrumbs] = useState<NavigationStackEntry[]>([])

  return (
    <>
      {/* External breadcrumb UI */}
      <nav className="breadcrumbs-bar">
        {breadcrumbs.map((entry, i) => (
          <React.Fragment key={entry.menuId}>
            {i > 0 && <span>/</span>}
            <span>{entry.menuTitle || entry.menuId}</span>
          </React.Fragment>
        ))}
      </nav>

      {/* Command menu without internal breadcrumbs */}
      <CommandMenu
        menu={menu}
        showBreadcrumbs={false}
        onNavigationChange={({ nextBreadcrumbs }) => {
          setBreadcrumbs(nextBreadcrumbs)
        }}
      />
    </>
  )
}
```

## Breadcrumb State

### Reading Navigation State

Access navigation state via context in compound components:

```tsx
import { useCommandMenuContext } from '@bazza-ui/command-menu'

function CustomComponent() {
  const { navigationStack, isInSubmenu } = useCommandMenuContext()

  return (
    <div>
      {isInSubmenu && (
        <div>Current depth: {navigationStack.length}</div>
      )}
    </div>
  )
}
```

### Tracking with onNavigationChange

Track breadcrumb changes for analytics or state management:

```tsx
<CommandMenu
  menu={menu}
  onNavigationChange={({ direction, prevBreadcrumbs, nextBreadcrumbs }) => {
    console.log('Navigation depth:', nextBreadcrumbs.length)
    console.log('Current path:', nextBreadcrumbs.map(b => b.menuTitle).join(' / '))

    // Analytics
    analytics.track('command_menu_navigate', {
      direction,
      depth: nextBreadcrumbs.length,
      path: nextBreadcrumbs.map(b => b.menuId).join('.')
    })
  }}
/>
```

## Accessibility

Breadcrumbs enhance accessibility by:

1. **Visual orientation** - Users know where they are in the hierarchy
2. **Back navigation affordance** - Clear way to return to parent
3. **Keyboard support** - Escape/Left arrow work at any depth

### Dialog Title

The current menu title (from breadcrumbs) is used for the accessible dialog title:

```tsx
// At root
<Dialog.Title>Command Menu</Dialog.Title>

// In "Settings" submenu
<Dialog.Title>Settings Menu</Dialog.Title>

// In "Advanced Settings" submenu
<Dialog.Title>Advanced Settings</Dialog.Title>
```

This helps screen reader users understand context when the dialog opens or navigates.

## Common Patterns

### Compact Breadcrumbs

For tight spaces, show only the last breadcrumb:

```tsx
theme={{
  classNames: {
    breadcrumbItem: cn(
      // Hide all but last breadcrumb
      '[&:not(:last-child)]:hidden',
      '@md:[&]:block' // Show all on medium+ screens
    ),
  },
}}
```

### Clickable Breadcrumbs

While not built-in, you can build clickable breadcrumbs with external UI:

```tsx
function ClickableBreadcrumbs({ breadcrumbs, onNavigateTo }) {
  return (
    <div>
      {breadcrumbs.map((entry, index) => (
        <button
          key={entry.menuId}
          onClick={() => onNavigateTo(index)}
          className="breadcrumb-link"
        >
          {entry.menuTitle}
        </button>
      ))}
    </div>
  )
}
```

### Breadcrumb Icons

Add icons to breadcrumbs by customizing the back button:

```tsx
theme={{
  classNames: {
    backButton: 'flex items-center gap-2',
  },
}}

// The back button automatically includes a chevron icon
// For custom icons, you'd need to use external breadcrumbs
```

## Best Practices

1. **Always provide titles** - Use descriptive `title` props for better breadcrumb clarity
2. **Keep breadcrumbs enabled** - Unless you have custom navigation UI
3. **Limit nesting depth** - 2-3 levels max for best UX
4. **Style consistently** - Match breadcrumbs to your design system
5. **Test keyboard navigation** - Ensure Escape/Left arrow work correctly
6. **Consider mobile** - Breadcrumbs should be readable on small screens
