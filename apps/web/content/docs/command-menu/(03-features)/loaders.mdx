# Async Data Loading

Load menu items dynamically using async loaders with full React Query integration, loading states, error handling, and streaming deep search.

## Overview

The command menu supports asynchronous data loading through a **LoaderAdapter** system. The TanStack Query (React Query) adapter is included, providing:

- Automatic caching and refetching
- Loading and error states
- Parallel query execution
- Streaming deep search
- Type-safe query configuration

## Basic Usage

### Install Dependencies

```bash
npm install @tanstack/react-query
```

### Setup Query Client

Wrap your app with QueryClientProvider:

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <YourApp />
    </QueryClientProvider>
  )
}
```

### Use the React Query Adapter

```tsx
import { CommandMenu } from '@bazza-ui/command-menu'
import { ReactQueryLoaderAdapter } from '@bazza-ui/command-menu/loaders/tanstack-query'

function MyCommandMenu() {
  return (
    <CommandMenu
      menu={{
        loader: {
          queryKey: ['commands'],
          queryFn: async () => {
            const response = await fetch('/api/commands')
            return response.json()
          },
        },
      }}
      loaderAdapter={ReactQueryLoaderAdapter}
    />
  )
}
```

## The createLoader Helper

For type-safe loaders with full React Query support, use `createLoader`:

```tsx
import { createLoader } from '@bazza-ui/command-menu/loaders/tanstack-query'

const menu = {
  loader: createLoader(({ query, open }) => ({
    queryKey: ['commands', query],
    queryFn: async () => {
      const response = await fetch(`/api/commands?q=${query}`)
      return response.json()
    },
    staleTime: 5000,
    retry: 3,
    enabled: open && query.length > 0,
  })),
}
```

### Loader Context

The `createLoader` callback receives an `AsyncNodeLoaderContext`:

```typescript
type AsyncNodeLoaderContext = {
  /** Current search query */
  query: string
  /** Whether the menu is open */
  open: boolean
  /** Menu ID */
  menuId: string
  /** Parent menu ID (if in submenu) */
  parentMenuId?: string
  /** Navigation depth */
  depth: number
}
```

### React Query Options

All React Query options are supported:

```tsx
loader: createLoader(({ query }) => ({
  queryKey: ['items', query],
  queryFn: () => fetchItems(query),
  // Caching
  staleTime: 5000,
  gcTime: 10 * 60 * 1000,
  // Refetching
  refetchOnWindowFocus: false,
  refetchOnMount: false,
  // Retry
  retry: 3,
  retryDelay: 1000,
  // Enable/disable
  enabled: query.length > 0,
  // Transformation
  select: (data) => transformData(data),
}))
```

## Loading States

The loader result provides comprehensive loading states:

```typescript
type AsyncNodeLoaderResult<T> = {
  /** Loaded data */
  data?: NodeDef<T>[]
  /** Initial loading state */
  isLoading: boolean
  /** Background fetching state */
  isFetching: boolean
  /** Error state */
  isError: boolean
  /** Error object */
  error: Error | null
}
```

### Custom Loading Component

```tsx
<CommandMenu
  menu={menu}
  loaderAdapter={ReactQueryLoaderAdapter}
  theme={{
    slots: {
      LoadingState: ({ progress }) => (
        <div className="p-8 text-center">
          <Spinner />
          <p>Loading commands...</p>
          {progress && (
            <div className="mt-2 text-sm text-gray-500">
              {progress.map(p => p.label).join(', ')}
            </div>
          )}
        </div>
      ),
    },
  }}
/>
```

## Search-Dependent Loading

Load different data based on the search query:

```tsx
loader: createLoader(({ query }) => ({
  queryKey: ['search', query],
  queryFn: async () => {
    if (!query) {
      // No query - show recent items
      return fetchRecentItems()
    }
    if (query.length < 2) {
      // Query too short - don't search
      return []
    }
    // Search API
    return searchCommands(query)
  },
  // Only run when there's a query
  enabled: query.length > 0,
}))
```

## Submenu Loaders

Each submenu can have its own loader:

```tsx
const menu = {
  nodes: [
    {
      kind: 'submenu',
      id: 'users',
      label: 'Users',
      // Loader for the submenu
      loader: createLoader(({ query }) => ({
        queryKey: ['users', query],
        queryFn: () => fetchUsers(query),
      })),
    },
    {
      kind: 'submenu',
      id: 'settings',
      label: 'Settings',
      // Different loader for settings
      loader: createLoader(() => ({
        queryKey: ['settings'],
        queryFn: () => fetchSettings(),
        staleTime: Infinity, // Never refetch
      })),
    },
  ],
}
```

## Data Transformation

Use the `select` option to transform API data:

```tsx
type APIResponse = {
  id: string
  name: string
  description: string
}

loader: createLoader<APIResponse[]>(({ query }) => ({
  queryKey: ['items', query],
  queryFn: () => fetch('/api/items').then(r => r.json()),
  // Transform to NodeDef format
  select: (data) => data.map(item => ({
    kind: 'item' as const,
    id: item.id,
    label: item.name,
    description: item.description,
    data: item, // Store raw data
  })),
}))
```

## Deep Search

The command menu supports **streaming deep search** - searching all submenus recursively while the user types.

### How It Works

1. User types in search input
2. Menu searches root nodes
3. **Simultaneously** searches all submenus in parallel
4. Results from all levels appear in a flat list
5. When user selects a deep result, it navigates to that submenu

### Enable Deep Search

Deep search requires the loader to support it:

```tsx
loader: createLoader(({ query, depth }) => ({
  queryKey: ['commands', query, depth],
  queryFn: () => fetchCommands({ query, depth }),
  // Enable for deep search
  enabled: query.length > 0,
}))
```

### Deep Search Example

```tsx
const menu = {
  nodes: [
    {
      kind: 'submenu',
      id: 'file',
      label: 'File',
      // This loader runs during deep search
      loader: createLoader(({ query }) => ({
        queryKey: ['file-commands', query],
        queryFn: async () => [
          { kind: 'item', id: 'new', label: 'New File', keywords: ['create'] },
          { kind: 'item', id: 'open', label: 'Open File', keywords: ['browse'] },
        ],
      })),
      nodes: [
        {
          kind: 'submenu',
          id: 'export',
          label: 'Export',
          // Nested loader also runs during deep search
          loader: createLoader(({ query }) => ({
            queryKey: ['export-commands', query],
            queryFn: async () => [
              { kind: 'item', id: 'pdf', label: 'Export as PDF' },
              { kind: 'item', id: 'csv', label: 'Export as CSV' },
            ],
          })),
        },
      ],
    },
  ],
}

// User types "pdf" → all loaders run → "Export as PDF" appears in root list
```

### Deep Search Performance

All submenu loaders run in **parallel** using `useQueries`:

```tsx
// The adapter executes these simultaneously:
useQueries({
  queries: [
    { queryKey: ['file-commands', 'pdf'] },
    { queryKey: ['edit-commands', 'pdf'] },
    { queryKey: ['view-commands', 'pdf'] },
    { queryKey: ['export-commands', 'pdf'] },
    // ... all other submenus
  ],
})
```

## Conditional Loading

Only load when certain conditions are met:

```tsx
loader: createLoader(({ query, open, depth }) => ({
  queryKey: ['items', query],
  queryFn: () => fetchItems(query),
  enabled: (
    open && // Menu is open
    query.length >= 2 && // Minimum query length
    depth === 0 // Only at root level
  ),
}))
```

## Caching Strategy

### Aggressive Caching

For static data that rarely changes:

```tsx
loader: createLoader(() => ({
  queryKey: ['static-commands'],
  queryFn: () => fetchCommands(),
  staleTime: Infinity,
  gcTime: Infinity,
}))
```

### Fresh Data

For real-time data that should refetch:

```tsx
loader: createLoader(() => ({
  queryKey: ['live-data'],
  queryFn: () => fetchLiveData(),
  staleTime: 0,
  refetchInterval: 5000, // Refetch every 5s
}))
```

### Query-Based Caching

Cache separately per query:

```tsx
loader: createLoader(({ query }) => ({
  queryKey: ['search', query],
  queryFn: () => search(query),
  staleTime: 60 * 1000, // Cache for 1 minute
}))
```

## Error Handling

### Retry on Failure

```tsx
loader: createLoader(() => ({
  queryKey: ['items'],
  queryFn: fetchItems,
  retry: 3,
  retryDelay: (attemptIndex) => Math.min(1000 * 2 ** attemptIndex, 30000),
}))
```

### Custom Error Messages

```tsx
loader: createLoader(() => ({
  queryKey: ['items'],
  queryFn: async () => {
    const response = await fetch('/api/items')
    if (!response.ok) {
      throw new Error('Failed to load commands. Please try again.')
    }
    return response.json()
  },
}))
```

### Graceful Fallback

```tsx
loader: createLoader(() => ({
  queryKey: ['items'],
  queryFn: fetchItems,
  placeholderData: [], // Show empty list while loading
  retry: false,
}))
```

## Custom Loader Adapter

Create your own adapter for other data fetching libraries:

```tsx
import type { LoaderAdapter } from '@bazza-ui/menu'

const MyCustomAdapter: LoaderAdapter = {
  useLoader(loader, context) {
    // Your loading logic
    const { data, isLoading, error } = useYourFetchHook(loader, context)

    return {
      data,
      isLoading,
      error: error || null,
      isError: !!error,
      isFetching: isLoading,
    }
  },

  useLoaders(loaders) {
    // Batch loading logic for deep search
    const results = loaders.map(({ loader, context }) =>
      this.useLoader(loader, context)
    )

    return new Map(
      loaders.map(({ path }, i) => [path.join('.'), results[i]])
    )
  },
}
```

## TypeScript

Full type safety with generics:

```tsx
import { createLoader } from '@bazza-ui/command-menu/loaders/tanstack-query'

type MyData = {
  id: string
  name: string
  icon: React.ReactNode
}

type APIResponse = {
  items: Array<{ id: string; title: string }>
}

const menu = {
  loader: createLoader<APIResponse>(({ query }) => ({
    queryKey: ['items', query],
    queryFn: () => fetch('/api').then(r => r.json()),
    // data is typed as APIResponse
    select: (data) => data.items.map(item => ({
      kind: 'item' as const,
      id: item.id,
      label: item.title,
      data: item, // Typed as MyData
    })),
  })),
}
```

## Best Practices

1. **Use createLoader** - Provides full type safety and autocomplete
2. **Set appropriate staleTime** - Prevent unnecessary refetches
3. **Use enabled wisely** - Don't load until needed
4. **Cache by query** - Include query in queryKey for proper caching
5. **Handle errors gracefully** - Provide fallback UI
6. **Optimize deep search** - Use enabled to prevent excessive parallel queries
7. **Transform in select** - Keep queryFn simple, transform in select
8. **Test loading states** - Ensure UI handles all states (loading, error, empty)
