A context menu displays a list of options when triggered by a right-click (or long-press on touch devices). It supports all the same features as dropdown menus: items, checkbox items, radio groups, nested submenus, keyboard navigation, and deep search filtering.

## Installation

```bash
bun add @bazza-ui/react
```

## Basic Usage

```tsx
import { ContextMenu } from '@bazza-ui/react'

function Demo() {
  return (
    <ContextMenu.Root>
      <ContextMenu.Trigger>
        <div className="p-8 border rounded-lg">
          Right-click here
        </div>
      </ContextMenu.Trigger>
      <ContextMenu.Portal>
        <ContextMenu.Positioner>
          <ContextMenu.Popup>
            <ContextMenu.Item onSelect={() => console.log('Cut')}>
              Cut
            </ContextMenu.Item>
            <ContextMenu.Item onSelect={() => console.log('Copy')}>
              Copy
            </ContextMenu.Item>
            <ContextMenu.Item onSelect={() => console.log('Paste')}>
              Paste
            </ContextMenu.Item>
            <ContextMenu.Separator />
            <ContextMenu.Item onSelect={() => console.log('Delete')}>
              Delete
            </ContextMenu.Item>
          </ContextMenu.Popup>
        </ContextMenu.Positioner>
      </ContextMenu.Portal>
    </ContextMenu.Root>
  )
}
```

## Features

- **Right-click activation** - Opens on right-click (contextmenu event)
- **Touch support** - Opens on long-press for touch devices
- **Virtual anchor** - Menu appears at cursor position
- **Accessible** - Full keyboard navigation and ARIA attributes
- **Composable** - Build menus with any combination of items, checkboxes, radio groups, and submenus
- **Deep Search** - Built-in typeahead filtering with fuzzy matching
- **Submenus** - Nested menus with intelligent aim tracking

## Differences from Dropdown Menu

| Feature | Context Menu | Dropdown Menu |
|---------|-------------|---------------|
| Trigger | Right-click / long-press | Click on button |
| Anchor | Cursor position | Trigger element |
| Use case | Contextual actions | Navigation / actions |

### Trigger Behavior

The key difference from Dropdown Menu is how the menu is triggered:

```tsx
<ContextMenu.Root>
  {/* The Trigger wraps an element that responds to right-click */}
  <ContextMenu.Trigger>
    <div className="p-8 border rounded-lg">
      Right-click anywhere in this area
    </div>
  </ContextMenu.Trigger>
  ...
</ContextMenu.Root>
```

**Trigger Events:**
- **Desktop**: Right-click (`contextmenu` event)
- **Touch**: Long-press (press and hold)

### Virtual Anchor Positioning

Unlike Dropdown Menu which anchors to the trigger element, Context Menu positions itself at the cursor location. The menu appears where the user clicked:

```tsx
<ContextMenu.Positioner>
  {/* Menu appears at click coordinates, not attached to trigger element */}
  <ContextMenu.Popup>
    ...
  </ContextMenu.Popup>
</ContextMenu.Positioner>
```

This creates a more natural "right-click menu" experience where actions appear directly under the cursor.

### Data-First API

The Data-First API provides a declarative way to define menu content using data structures instead of JSX. It enables deep search functionality that can search through nested submenus and supports dynamic filtering.

#### Surface

Pass `content` or `asyncContent` to `Surface` to enable data-first mode. In data-first mode, `Surface` provides deep search functionality and disables built-in item filtering so `List` can render data nodes.

<TypeTableAuto type="ContextMenuSurfaceProps" pkg="@bazza-ui/react" />

#### List

When placed inside a data `Surface`, `List` computes the visible data nodes and provides them through `useDataList()`. Renders a `<div>` element with `role="listbox"`.

<TypeTableAuto type="ContextMenuListProps" pkg="@bazza-ui/react" />

#### Input

A text input for filtering menu items. In data-first mode, it controls the `Surface` search state used by `List` and `useDataList()`.

<TypeTableAuto type="ContextMenuInputProps" pkg="@bazza-ui/react" />

#### useDataList

Reads the computed data-list state from a `List` inside a data `Surface`, including visible nodes, the node renderer, result count, and async state.

<TypeTableAuto type="DataListChildrenState" pkg="@bazza-ui/react" />

### Node Definition Types

Context Menu uses the same node definition types as Dropdown Menu for the Data-First API. See the [Dropdown Menu Node Definition Types](/docs/dropdown-menu#node-definition-types) documentation for:

- `NodeDef` - Union type of all node definitions
- `ItemDef`, `SubmenuDef`, `CheckboxItemDef`, `RadioItemDef`, `RadioGroupDef`, `GroupDef`, `SeparatorDef`
- `ItemRenderParams`, `SubmenuRenderParams`, and other render parameter types
- `BreadcrumbNode`, `RowRenderContext`, `DeepSearchConfig`
