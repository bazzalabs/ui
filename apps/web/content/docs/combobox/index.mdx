A combobox combines a text input with a dropdown list of suggestions. It's ideal for autocomplete scenarios, searchable selects, and tagging interfaces. Supports both single-value and multi-value selection modes.

## Installation

```bash
bun add @bazza-ui/react
```

## Basic Usage

```tsx
import { Combobox } from '@bazza-ui/react'

function Demo() {
  const [value, setValue] = React.useState('')

  return (
    <Combobox.Root value={value} onValueChange={setValue}>
      <Combobox.InputWrapper>
        <Combobox.Input placeholder="Search fruits..." />
        <Combobox.Clear />
      </Combobox.InputWrapper>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.Item value="apple">
              <Combobox.ItemIndicator />
              <Combobox.ItemLabel>Apple</Combobox.ItemLabel>
            </Combobox.Item>
            <Combobox.Item value="banana">
              <Combobox.ItemIndicator />
              <Combobox.ItemLabel>Banana</Combobox.ItemLabel>
            </Combobox.Item>
            <Combobox.Item value="orange">
              <Combobox.ItemIndicator />
              <Combobox.ItemLabel>Orange</Combobox.ItemLabel>
            </Combobox.Item>
            <Combobox.Empty>No fruits found</Combobox.Empty>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  )
}
```

## Features

- **Autocomplete** - Filter suggestions as user types
- **Single & Multi-select** - Support for selecting one or multiple values
- **Free-form input** - Allow users to enter custom values not in the list
- **Fuzzy matching** - Built-in fuzzy search algorithm
- **Groups** - Organize options into labeled groups
- **Virtualized** - Support for virtualized lists with thousands of items
- **Controlled & Uncontrolled** - Works in both modes

### Multi-Select Tags

```tsx
function TagsCombobox() {

      value={values}
```

### With Object Values

Use objects as values for complex data structures:

```tsx
interface User {
  id: number
  name: string
  email: string
}

const users: User[] = [
  { id: 1, name: 'John Doe', email: 'john@example.com' },
  { id: 2, name: 'Jane Smith', email: 'jane@example.com' },
  { id: 3, name: 'Bob Wilson', email: 'bob@example.com' },
]

function UserCombobox() {
  const [selected, setSelected] = React.useState<User | null>(null)

  return (
    <Combobox.Root
      value={selected}
      onValueChange={setSelected}
      isItemEqualToValue={(a, b) => a.id === b.id}
      itemToStringLabel={(u) => u.name}
      itemToStringValue={(u) => String(u.id)}
    >
      <Combobox.InputWrapper>
        <Combobox.Input placeholder="Search users..." />
        <Combobox.Clear />
      </Combobox.InputWrapper>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.Surface>
              <Combobox.List>
                {users.map((user) => (
                  <Combobox.Item key={user.id} value={user}>
                    <Combobox.ItemIndicator />
                    <div>
                      <Combobox.ItemLabel />
                      <span className="text-muted-foreground text-sm">
                        {user.email}
                      </span>
                    </div>
                  </Combobox.Item>
                ))}
              </Combobox.List>
              <Combobox.Empty>No users found</Combobox.Empty>
            </Combobox.Surface>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  )
}
```

## Guides

### Basics

Combobox combines a text input with a dropdown list of suggestions. It's ideal for autocomplete scenarios.

#### Controlled vs Uncontrolled

```tsx
// Uncontrolled - Combobox manages its own value
<Combobox.Root defaultValue="">
  ...
</Combobox.Root>

// Controlled - You manage the value
const [value, setValue] = React.useState('')

<Combobox.Root value={value} onValueChange={setValue}>
  ...
</Combobox.Root>
```

---

### Multi-Select Mode

Enable multi-select for tagging interfaces:

```tsx
const [values, setValues] = React.useState<string[]>([])

<Combobox.Root multiple values={values} onValuesChange={setValues}>
  <Combobox.InputWrapper>
    {/* Render selected tags */}
    <div className="flex flex-wrap gap-1">
      {values.map((tag) => (
        <span key={tag} className="px-2 py-1 bg-blue-100 rounded text-sm">
          {tag}
          <button onClick={() => setValues(values.filter(v => v !== tag))}>
            x
          </button>
        </span>
      ))}
      <Combobox.Input placeholder="Add tags..." />
    </div>
    <Combobox.Clear />
  </Combobox.InputWrapper>
  ...
</Combobox.Root>
```

### Filtering

Combobox filters automatically as users type. The built-in fuzzy search uses the `commandScore` algorithm.

#### Value and Keywords

Use `value` and `keywords` for better matching:

```tsx
<Combobox.Item value="apple" keywords={['fruit', 'red', 'healthy']}>
  Apple
</Combobox.Item>
```

#### Custom Filter Function

Replace the default fuzzy search:

```tsx
<Combobox.Surface
  filter={(value, search, keywords) => {
    // Return score between 0 (no match) and 1 (perfect match)
    return value.toLowerCase().startsWith(search.toLowerCase()) ? 1 : 0
  }}
>
  ...
</Combobox.Surface>
```

### Virtualization

For large lists, use virtualization:

```tsx
import { useVirtualizer } from '@tanstack/react-virtual'

const items = Array.from({ length: 1000 }, (_, i) => ({
  value: `item-${i}`,
  label: `Item ${i}`,
}))

function VirtualizedCombobox() {
  const scrollRef = React.useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => scrollRef.current,
    estimateSize: () => 36,
  })

  return (
    <Combobox.Root
      virtualized
      virtualItems={items}
      onHighlightChange={(id, index) => {
        virtualizer.scrollToIndex(index, { align: 'auto' })
      }}
    >
      <Combobox.InputWrapper>
        <Combobox.Input placeholder="Search items..." />
      </Combobox.InputWrapper>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.Surface filter={false}>
              <Combobox.List viewportRef={scrollRef}>
                <div style={{ height: virtualizer.getTotalSize() }}>
                  {virtualizer.getVirtualItems().map((row) => (
                    <div
                      key={row.key}
                      style={{
                        position: 'absolute',
                        top: row.start,
                        height: row.size,
                        width: '100%',
                      }}
                    >
                      <Combobox.Item value={items[row.index].value}>
                        <Combobox.ItemIndicator />
                        <Combobox.ItemLabel>{items[row.index].label}</Combobox.ItemLabel>
                      </Combobox.Item>
                    </div>
                  ))}
                </div>
              </Combobox.List>
            </Combobox.Surface>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  )
}
```

### Object Values

Combobox supports using objects as values instead of just strings. This is useful when working with complex data structures like database records or API responses.

#### Auto-detected `{ value, label }` Objects

If your objects have a `value` and `label` property, Combobox will automatically use them:

```tsx
interface Fruit {
  value: string
  label: string
}

const fruits: Fruit[] = [
  { value: 'apple', label: 'Apple' },
  { value: 'banana', label: 'Banana' },
  { value: 'cherry', label: 'Cherry' },
]

function ObjectCombobox() {
  const [selected, setSelected] = React.useState<Fruit | null>(null)

  return (
    <Combobox.Root value={selected} onValueChange={setSelected}>
      <Combobox.InputWrapper>
        <Combobox.Input placeholder="Search fruits..." />
      </Combobox.InputWrapper>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.Surface>
              <Combobox.List>
                {fruits.map((fruit) => (
                  <Combobox.Item key={fruit.value} value={fruit}>
                    <Combobox.ItemIndicator />
                    <Combobox.ItemLabel />
                  </Combobox.Item>
                ))}
              </Combobox.List>
            </Combobox.Surface>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  )
}
```

- **Display**: Uses `label` property for input display and `<Combobox.ItemLabel>`
- **Form submission**: Uses `value` property for hidden form inputs
- **Equality**: Uses reference equality by default

#### Custom Object Shapes

For objects with different shapes, use `isItemEqualToValue`, `itemToStringLabel`, and `itemToStringValue`:

```tsx
interface User {
  id: number
  firstName: string
  lastName: string
  email: string
}

const users: User[] = [
  { id: 1, firstName: 'John', lastName: 'Doe', email: 'john@example.com' },
  { id: 2, firstName: 'Jane', lastName: 'Smith', email: 'jane@example.com' },
]

function UserCombobox() {
  const [selected, setSelected] = React.useState<User | null>(null)

  return (
    <Combobox.Root
      value={selected}
      onValueChange={setSelected}
      // Compare by ID instead of reference
      isItemEqualToValue={(item, value) => item.id === value.id}
      // Display full name in input
      itemToStringLabel={(user) => `${user.firstName} ${user.lastName}`}
      // Submit ID to form
      itemToStringValue={(user) => String(user.id)}
    >
      <Combobox.InputWrapper>
        <Combobox.Input placeholder="Search users..." />
        <Combobox.Clear />
      </Combobox.InputWrapper>
      <Combobox.Portal>
        <Combobox.Positioner>
          <Combobox.Popup>
            <Combobox.Surface>
              <Combobox.List>
                {users.map((user) => (
                  <Combobox.Item key={user.id} value={user}>
                    <Combobox.ItemIndicator />
                    <Combobox.ItemLabel />
                  </Combobox.Item>
                ))}
              </Combobox.List>
            </Combobox.Surface>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  )
}
```

**Props explained:**

| Prop | Purpose | Example |
|------|---------|---------|
| `isItemEqualToValue` | Compare item to selected value | `(a, b) => a.id === b.id` |
| `itemToStringLabel` | Convert object to display string | `(u) => u.name` |
| `itemToStringValue` | Convert object for form submission | `(u) => String(u.id)` |

#### Multi-Select with Objects

Object values work with multi-select too:

```tsx
const [selected, setSelected] = React.useState<User[]>([])

<Combobox.Root
  multiple
  values={selected}
  onValuesChange={setSelected}
  isItemEqualToValue={(a, b) => a.id === b.id}
  itemToStringLabel={(u) => u.name}
>
  <Combobox.InputWrapper>
    <div className="flex flex-wrap gap-1">
      {selected.map((user) => (
        <span key={user.id} className="px-2 py-1 bg-blue-100 rounded text-sm">
          {user.name}
          <button onClick={() => setSelected(selected.filter(u => u.id !== user.id))}>
            ×
          </button>
        </span>
      ))}
      <Combobox.Input placeholder="Add users..." />
    </div>
  </Combobox.InputWrapper>
  ...
</Combobox.Root>
```

## Differences from Select

| Feature | Combobox | Select |
|---------|----------|--------|
| Input | Text input for typing | Button trigger |
| Filtering | As-you-type filtering | Optional search input |
| Custom values | Can allow free-form input | No custom values |
| Multi-select | Native support | Native support |
| Use case | Autocomplete, tagging | Single selection |
