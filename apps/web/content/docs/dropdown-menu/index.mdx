## Installation

```npm
npx shadcn@latest add https://bazza-ui.com/r/dropdown-menu
```

```tsx
import { DropdownMenu } from '@/components/ui/dropdown-menu';
```

If you want to install the unstyled, primitive component:

```npm
npm install @bazza-ui/react
```

```tsx
import { DropdownMenu } from '@bazza-ui/react';
```

## Anatomy

```tsx
<DropdownMenu.Root>
  <DropdownMenu.Trigger />
  <DropdownMenu.Portal>
    <DropdownMenu.Backdrop />
    <DropdownMenu.Positioner>
      <DropdownMenu.Popup>
        <DropdownMenu.Arrow />
        <DropdownMenu.Surface>
          <DropdownMenu.Input />
          <DropdownMenu.List>
            {/* Scroll up/down arrows */}
            <DropdownMenu.ScrollUpArrow />
            <DropdownMenu.ScrollDownArrow />
            {/* Items */}
            <DropdownMenu.Item>
              <DropdownMenu.Icon />
              <DropdownMenu.Shortcut />
            </DropdownMenu.Item>
            {/* Groups */}
            <DropdownMenu.Group>
              <DropdownMenu.GroupLabel />
            </DropdownMenu.Group>
            {/* Checkbox items */}
            <DropdownMenu.CheckboxItem>
              <DropdownMenu.CheckboxItemIndicator />
            </DropdownMenu.CheckboxItem>
            {/* Radio group + radio items */}
            <DropdownMenu.RadioGroup>
              <DropdownMenu.RadioItem>
                <DropdownMenu.RadioItemIndicator />
              </DropdownMenu.RadioItem>
            </DropdownMenu.RadioGroup>
            {/* Separator */}
            <DropdownMenu.Separator />
            {/* Submenus */}
            <DropdownMenu.Submenu>
              {/* Submenu Trigger */}
              <DropdownMenu.SubmenuTrigger>
                <DropdownMenu.SubmenuTriggerIndicator />
              </DropdownMenu.SubmenuTrigger>
            </DropdownMenu.Submenu>
            <DropdownMenu.Empty />
          </DropdownMenu.List>
        </DropdownMenu.Surface>
      </DropdownMenu.Popup>
    </DropdownMenu.Positioner>
  </DropdownMenu.Portal>
</DropdownMenu.Root>
```

## Guides

### Basics

The dropdown menu is built around a trigger-popup pattern. When the trigger is activated (clicked or via keyboard), the popup opens with a list of selectable items.

#### Controlled vs Uncontrolled

The menu can be used in either controlled or uncontrolled mode:

```tsx
// Uncontrolled (default) - menu manages its own state
<DropdownMenu.Root>
  ...
</DropdownMenu.Root>

// Controlled - you manage the open state
const [open, setOpen] = React.useState(false)

<DropdownMenu.Root open={open} onOpenChange={setOpen}>
  ...
</DropdownMenu.Root>
```

#### Open Change Events

The `onOpenChange` callback receives event details explaining why the menu opened or closed:

```tsx
<DropdownMenu.Root
  onOpenChange={(open, details) => {
    console.log(details.reason) // 'triggerPress', 'escapeKey', 'outsidePress', etc.
    console.log(details.event)  // The original DOM event (if available)
  }}
>
```

**Reasons include:**
- `triggerPress` - User clicked the trigger
- `escapeKey` - User pressed Escape
- `outsidePress` - User clicked outside the menu
- `itemPress` - User selected an item
- `focusOut` - Focus moved outside the menu

---

### Item Selection

Each item accepts an `onSelect` callback that fires when the item is activated via click or keyboard (Enter/Space):

```tsx
<DropdownMenu.Item onSelect={() => console.log('Selected!')}>
  Click me
</DropdownMenu.Item>
```

#### Close on Click

By default, selecting an item closes the menu. Override this with `closeOnClick`:

```tsx
// Item that doesn't close the menu when selected
<DropdownMenu.Item closeOnClick={false} onSelect={handleSelect}>
  Stay Open
</DropdownMenu.Item>
```

Default `closeOnClick` values by item type:
- `Item`: `true` (closes menu)
- `CheckboxItem`: `false` (stays open)
- `RadioItem`: `false` (stays open)

#### Disabled Items

Disabled items cannot be selected and are skipped during keyboard navigation:

```tsx
<DropdownMenu.Item disabled>
  Can't click this
</DropdownMenu.Item>
```

---

### Search & Filtering

Add a search input to let users filter items. The built-in fuzzy search uses the `commandScore` algorithm (same as cmdk).

```tsx
<DropdownMenu.Surface>
  <DropdownMenu.Input placeholder="Search..." />
  <DropdownMenu.List>
    <DropdownMenu.Item value="copy">Copy</DropdownMenu.Item>
    <DropdownMenu.Item value="paste">Paste</DropdownMenu.Item>
  </DropdownMenu.List>
  <DropdownMenu.Empty>No results found</DropdownMenu.Empty>
</DropdownMenu.Surface>
```

#### Value and Keywords

The `value` prop is used for filtering. If not provided, the item's text content is used:

```tsx
// Filter by explicit value
<DropdownMenu.Item value="copy-to-clipboard">Copy</DropdownMenu.Item>

// Add additional keywords for better matching
<DropdownMenu.Item value="bug" keywords={['issue', 'problem', 'error']}>
  Report Bug
</DropdownMenu.Item>
```

#### Hidden Until Active

For a cleaner look, hide the input until the user starts typing:

```tsx
<DropdownMenu.Input hideUntilActive placeholder="Type to search..." />
```

#### Custom Filter Function

Replace the default fuzzy search with your own filter:

```tsx
<DropdownMenu.Surface
  filter={(value, search, keywords) => {
    // Return a score between 0 (no match) and 1 (perfect match)
    const match = value.toLowerCase().startsWith(search.toLowerCase())
    return match ? 1 : 0
  }}
>
  ...
</DropdownMenu.Surface>
```

Set `filter={false}` to disable filtering entirely (useful when you handle filtering externally, e.g., with virtualization).

### Submenus

```tsx
<DropdownMenu.Submenu>
  <DropdownMenu.SubmenuTrigger>

      </DropdownMenu.Popup>
    </DropdownMenu.Positioner>
  </DropdownMenu.Portal>
</DropdownMenu.Submenu>
```

#### Aim Guard

Submenus include "aim guard" - intelligent mouse tracking that allows diagonal movement toward an open submenu without accidentally closing it.

#### Submenu Positioning

Submenus default to `side="right"` and `align="start"`. Customize via the Positioner:

```tsx
<DropdownMenu.Positioner side="left" align="end">
  ...
</DropdownMenu.Positioner>
```

### Keyboard Shortcuts

Display keyboard shortcuts alongside items:

```tsx
<DropdownMenu.Item shortcut="c">
  Copy
  <DropdownMenu.Shortcut>Ctrl+C</DropdownMenu.Shortcut>
</DropdownMenu.Item>
```

The `shortcut` prop on `Item` enables single-character keyboard activation (pressing "c" while the menu is open will select the item).

---

### Value vs ID

Understanding the difference between `value` and `id`:

| Prop | Purpose | When to Use |
|------|---------|-------------|
| `value` | Human-readable text for filtering and display | Always (required or inferred from content) |
| `id` | Explicit unique identifier | When you need stable, predictable IDs |

```tsx
// value is inferred from text content
<DropdownMenu.Item>Copy</DropdownMenu.Item>

// Explicit value for better filtering
<DropdownMenu.Item value="copy-to-clipboard">Copy</DropdownMenu.Item>

// Explicit ID when you need a predictable identifier
<DropdownMenu.Item id="action-copy" value="copy">Copy</DropdownMenu.Item>
```

When using the Data-First API with deep search, IDs become more important for tracking items across nested menus. See the [Deep Search](#deep-search--data-first-api) section.

### Deep Search & Data-First API

Deep search allows users to search across all nested submenus from the root menu. Instead of navigating into each submenu, matching items from any level are surfaced in a flat list.

This is powered by the **Data-First API** - a declarative approach where you define menu content as data (`NodeDef` objects) with render functions.

#### Basic Setup

```tsx
import type { NodeDef, ItemDef, SubmenuDef } from '@bazza-ui/react'

// Define items as data
const menuContent: NodeDef[] = [
  {
    kind: 'item',
    value: 'Copy',
    render: ({ props }) => (
      <DropdownMenu.Item {...props}>Copy</DropdownMenu.Item>
    ),
  },
  {
    kind: 'submenu',
    value: 'More Options',
    nodes: [
      {
        kind: 'item',
        value: 'Option A',
        render: ({ props }) => (
          <DropdownMenu.Item {...props}>Option A</DropdownMenu.Item>
        ),
      },
    ],
    render: ({ props, nodes, renderNode }) => (
      <DropdownMenu.Submenu>
        <DropdownMenu.SubmenuTrigger {...props}>
          More Options
        </DropdownMenu.SubmenuTrigger>
        <DropdownMenu.Portal>
          <DropdownMenu.Positioner>
            <DropdownMenu.Popup>
              <DropdownMenu.DataSurface content={nodes}>
                <DropdownMenu.DataList>
                  {({ nodes, renderNode }) => (
                    <>{nodes.map(renderNode)}</>
                  )}
                </DropdownMenu.DataList>
              </DropdownMenu.DataSurface>
            </DropdownMenu.Popup>
          </DropdownMenu.Positioner>
        </DropdownMenu.Portal>
      </DropdownMenu.Submenu>
    ),
  },
]

// Use DataSurface and DataList instead of Surface and List
<DropdownMenu.Root>
  <DropdownMenu.Trigger>Open</DropdownMenu.Trigger>
  <DropdownMenu.Portal>
    <DropdownMenu.Positioner>
      <DropdownMenu.Popup>
        <DropdownMenu.DataSurface
          content={menuContent}
          deepSearch={{ enabled: true, minLength: 0 }}
        >
          <DropdownMenu.DataInput placeholder="Search all..." />
          <DropdownMenu.DataList>
            {({ nodes, renderNode }) => (
              <>{nodes.map(renderNode)}</>
            )}
          </DropdownMenu.DataList>
        </DropdownMenu.DataSurface>
      </DropdownMenu.Popup>
    </DropdownMenu.Positioner>
  </DropdownMenu.Portal>
</DropdownMenu.Root>
```

#### Node Definition Types

| Kind | Description |
|------|-------------|
| `item` | Standard selectable item |
| `submenu` | Submenu trigger with nested content |
| `checkbox-item` | Toggleable checkbox item |
| `radio-item` | Radio option (use inside `radio-group`) |
| `radio-group` | Container for radio items |
| `group` | Container for grouping items |
| `separator` | Visual separator |

#### The Render Function

Each node's `render` function receives context about how the item should be displayed:

```tsx
{
  kind: 'item',
  value: 'Copy',
  render: ({ props, context }) => {
    // props: { id, value, disabled, ... } - spread onto the component
    // context.highlighted: boolean
    // context.disabled: boolean
    // context.search: { query, score } | null
    // context.breadcrumbs: BreadcrumbNode[] - path from root to this item
    // context.isDeepSearchResult: boolean - true if surfaced from a submenu

    return (
      <DropdownMenu.Item {...props}>
        {context.isDeepSearchResult && (
          <span className="text-muted-foreground text-xs">
            {context.breadcrumbs.map(b => b.value).join(' > ')}
          </span>
        )}
        Copy
      </DropdownMenu.Item>
    )
  },
}
```

#### Deep Search Configuration

```tsx
<DropdownMenu.DataSurface
  content={menuContent}
  deepSearch={{
    enabled: true,
    minLength: 0, // Start searching immediately (default: 0)
    groupSearchBehavior: 'preserve', // 'flatten' | 'preserve'
    radioGroupSearchBehavior: 'preserve', // 'flatten' | 'preserve' | 'preserve-show-all'
    sortGroups: true, // Sort groups by best match score
  }}
>
```

#### Custom ID Generation

When items from different submenus might have the same value, use `getQualifiedRowId` to generate unique IDs:

```tsx
<DropdownMenu.Root
  getQualifiedRowId={(ctx) => {
    // ctx.id - explicit ID if provided
    // ctx.value - the item's value
    // ctx.breadcrumbs - path from root
    // ctx.isDeepSearchResult - whether surfaced via search

    if (ctx.id) return ctx.id // Use explicit ID if provided

    // Build path-qualified ID: "status.in-progress"
    const path = ctx.breadcrumbs.map(b => b.value.toLowerCase())
    return [...path, ctx.value.toLowerCase()].join('.')
  }}
>
```

### Virtualization

For menus with many items (100+), use virtualization to render only visible items:

```tsx
import { useVirtualizer } from '@tanstack/react-virtual'

const items = Array.from({ length: 1000 }, (_, i) => ({
  value: `item-${i}`,
  label: `Item ${i}`,
}))

function VirtualizedMenu() {
  const scrollRef = React.useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => scrollRef.current,
    estimateSize: () => 36,
  })

  return (
    <DropdownMenu.Root
      virtualized
      items={items} // Pre-register items for navigation
      onHighlightChange={(id, index) => {
        // Sync scroll when highlight changes via keyboard
        virtualizer.scrollToIndex(index, { align: 'auto' })
      }}
    >
      <DropdownMenu.Trigger>Select Item</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Positioner>
          <DropdownMenu.Popup>
            <DropdownMenu.Surface filter={false}>
              <DropdownMenu.List viewportRef={scrollRef}>
                <div style={{ height: virtualizer.getTotalSize() }}>
                  {virtualizer.getVirtualItems().map((row) => (
                    <div
                      key={row.key}
                      style={{
                        position: 'absolute',
                        top: row.start,
                        height: row.size,
                        width: '100%',
                      }}
                    >
                      <DropdownMenu.Item value={items[row.index].value}>
                        {items[row.index].label}
                      </DropdownMenu.Item>
                    </div>
                  ))}
                </div>
              </DropdownMenu.List>
            </DropdownMenu.Surface>
          </DropdownMenu.Popup>
        </DropdownMenu.Positioner>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  )
}
```

**Key points:**
- Set `virtualized` on Root to enable virtualization mode
- Provide `items` array so navigation works for unmounted items
- Use `onHighlightChange` to sync virtualizer scroll
- Set `filter={false}` on Surface when handling filtering externally

### Data-First API

The Data-First API provides a declarative way to define menu content using data structures instead of JSX. It enables deep search functionality that can search through nested submenus and supports dynamic filtering.

#### DataSurface

Wraps the list and provides deep search functionality. Use instead of `Surface` when using the data-first approach. Renders a `<div>` element.
