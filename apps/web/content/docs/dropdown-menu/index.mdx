A dropdown menu displays a list of options when activated by a trigger element. It supports regular items, checkbox items, radio groups, nested submenus, keyboard navigation, and deep search filtering.

## Installation

```bash
bun add @bazza-ui/react
```

## Basic Usage

```tsx
import { DropdownMenu } from '@bazza-ui/react'

function Demo() {
  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>Open Menu</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Positioner>
          <DropdownMenu.Popup>
            <DropdownMenu.Item onSelect={() => console.log('New')}>
              New
            </DropdownMenu.Item>
            <DropdownMenu.Item onSelect={() => console.log('Open')}>
              Open
            </DropdownMenu.Item>
            <DropdownMenu.Separator />
            <DropdownMenu.Item onSelect={() => console.log('Save')}>
              Save
            </DropdownMenu.Item>
          </DropdownMenu.Popup>
        </DropdownMenu.Positioner>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  )
}
```

## Features

- **Accessible** - Full keyboard navigation and ARIA attributes
- **Composable** - Build menus with any combination of items, checkboxes, radio groups, and submenus
- **Deep Search** - Built-in typeahead filtering with fuzzy matching
- **Virtualized** - Support for virtualized lists with thousands of items
- **Submenus** - Nested menus with intelligent aim tracking
- **Controlled & Uncontrolled** - Works in both modes with `open` and `onOpenChange`

## Examples

### With Checkbox Items

```tsx
function CheckboxDemo() {
  const [showToolbar, setShowToolbar] = React.useState(true)
  const [showSidebar, setShowSidebar] = React.useState(false)

  return (
    <DropdownMenu.Root>
      <DropdownMenu.Trigger>View Options</DropdownMenu.Trigger>
      <DropdownMenu.Portal>
        <DropdownMenu.Positioner>
          <DropdownMenu.Popup>
            <DropdownMenu.CheckboxItem
              checked={showToolbar}
              onCheckedChange={setShowToolbar}
            >
              <DropdownMenu.CheckboxItemIndicator />
              Show Toolbar
            </DropdownMenu.CheckboxItem>
            <DropdownMenu.CheckboxItem
              checked={showSidebar}
              onCheckedChange={setShowSidebar}
            >
              <DropdownMenu.CheckboxItemIndicator />
              Show Sidebar
            </DropdownMenu.CheckboxItem>
          </DropdownMenu.Popup>
        </DropdownMenu.Positioner>
      </DropdownMenu.Portal>
    </DropdownMenu.Root>
  )
}
```

### Data-First API

The Data-First API provides a declarative way to define menu content using data structures instead of JSX. It enables deep search functionality that can search through nested submenus and supports dynamic filtering.

#### DataSurface

Wraps the list and provides deep search functionality. Use instead of `Surface` when using the data-first approach. Renders a `<div>` element.

<TypeTableAuto type="DropdownMenuDataSurfaceProps" pkg="@bazza-ui/react" />

#### DataList

Renders menu items from a data structure using a render prop pattern. Handles filtering, keyboard navigation, and dynamic rendering. Place inside `DataSurface`. Renders a `<div>` element with `role="listbox"`.

<TypeTableAuto type="DropdownMenuDataListProps" pkg="@bazza-ui/react" />

#### DataInput

A text input for filtering menu items in the data-first API. Functionally identical to the standard `Input` component. Renders an `<input>` element.
