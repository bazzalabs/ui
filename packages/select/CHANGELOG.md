# @bazza-ui/select

## 0.1.0-canary.0

### Minor Changes

- [#210](https://github.com/bazzalabs/ui/pull/210) [`54e7966`](https://github.com/bazzalabs/ui/commit/54e79662e9b62e144c2c46698dbd1c213cbcd8c5) Thanks [@kianbazza](https://github.com/kianbazza)! - Initial release of @bazza-ui/select package

  Add Select and MultiSelect components based on @bazza-ui/dropdown-menu with proper form integration and combobox/listbox ARIA pattern.

  Features:
  - Single and multi-select variants
  - Form integration with hidden inputs
  - Proper ARIA semantics (combobox/listbox pattern, not menu)
  - Type-level and runtime prevention of submenus
  - Full TypeScript support
  - Type-ahead search built-in
  - Virtualization for large lists
  - Async loading support
  - Programmatic control API
  - Works with React Hook Form and other form libraries

  Breaking changes:
  - None (new package)

  Migration:
  - No migration needed (new package)
